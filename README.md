# orders-sync

Мини-синхронизатор заявок: забирает `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`, отбрасывает невалидные, дедуплицирует по телефону и отдаёт JSON `{ clients, stats }`.

- Любой путь (`/`, `/sync`) запускает синхронизацию и возвращает результат.
- Телефон: из строки берутся только цифры; 11 цифр с ведущей `7`/`8` → `+7…`; 10 цифр (без кода страны) → дописывается `7`; всё остальное — невалидно.
- Дубли: остаётся запись с максимальным `amount`, при равенстве — с более поздним `created_at`.
- Идемпотентность: результат — детерминированная функция от входных данных (ключ — нормализованный телефон, клиенты отсортированы по телефону), повторные запуски возвращают байт-в-байт одинаковый ответ.
- `received = unique + duplicates_merged + invalid_dropped`.

Без зависимостей, Node 18+.

```
npm test
npm start   # http://localhost:3000
```

Деплой: Vercel (`api/index.js` + `vercel.json`) или любой хост с `node server.js`.
